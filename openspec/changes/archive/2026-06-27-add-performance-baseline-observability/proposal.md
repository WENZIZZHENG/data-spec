# 大字段库性能与可观测性基线

## 背景

字段库、SQL 检查记录、反向导入来源和 AI Context 变多后，DataSpec 的个人/小团队体验会直接受接口耗时影响。当前已有分页接口、字段推荐、按需 AI Context 和数据库 compare，但缺少一条可重复运行的本地性能基线，也缺少慢操作日志来提示用户或 AI agent 下一步该看哪里。

## 目标

- 新增轻量运行时性能探针，给核心慢操作输出结构化 warning。
- 新增合成大字段库性能基线测试，稳定覆盖字段分组/推荐、AI Context 字段目录导出和反向导入 compare。
- 更新 README/TODO，说明 P6-16 第一版能力、验证命令和边界。

## 非目标

- 不引入外部 APM、缓存集群或复杂监控平台。
- 不做真实数据库压测，不要求固定耗时阈值作为 CI 硬门槛。
- 不重构字段推荐、AI Context 或反向导入核心算法。

## 影响范围

- 后端：新增 common perf 工具和性能基线测试，给核心服务入口加慢操作日志。
- 文档：README/TODO 同步状态和验证入口。
- OpenSpec：新增 change/spec/tasks。
