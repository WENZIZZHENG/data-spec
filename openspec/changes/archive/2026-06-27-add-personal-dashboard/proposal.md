## 背景

P2-7 需要让个人/小团队打开 DataSpec 后能快速看到当前项目的规范沉淀效果。当前首页直接跳项目列表，标准字段数、代码集数、规则数量和最近 SQL 检查效果分散在不同页面。

## 变更

- 新增项目工作台汇总接口，返回字段数、代码集数、规则数、禁用词数量、最近检查次数、字段标准命中率、最近检查和问题趋势。
- 新增前端 Dashboard 页面，并将根路由默认指向 Dashboard。
- 侧边栏增加工作台入口。
- 命中率第一版基于最近 SQL 检查记录计算：最近记录中没有字段标准类问题的检查占比。

## 非目标

- 不做复杂资产驾驶舱、跨项目聚合或团队治理报表。
- 不引入图表库。
- 不做数据库反向导入或真实字段覆盖率扫描。
