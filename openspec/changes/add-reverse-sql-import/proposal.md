## 背景

P3-1 需要让已有数据库项目能从现有 schema 反向生成字段候选和规范差异。当前系统已有 SQL parser、字段标准和 lint，但没有专门的只读导入预览入口。

## 变更

- 新增反向导入预览 API，接收项目 ID 和 SQL DDL 文本。
- 复用 `SqlParserService` 解析 CREATE TABLE，输出表、字段候选、缺注释项和非标准字段差异。
- 新增前端反向导入页面，支持粘贴 SQL、上传 `.sql` 文件和查看预览结果。
- 第一版只读，不自动写入标准字段库。

## 非目标

- 不连接真实数据库。
- 不自动修改数据库或字段库。
- 不做完整 schema diff/迁移规划。
