## 设计

### 预览模型

后端返回：

- `tables`：解析出的表定义。
- `fieldCandidates`：SQL 中尚未命中标准字段库的字段候选。
- `missingComments`：表或列注释缺失项。
- `nonStandardFields`：字段名与标准字段库不匹配的差异项。
- `summary`：表数、字段数、候选数、缺注释数、非标准字段数。

### 匹配规则

- 字段命中：字段名与项目标准字段 `name` 完全一致，或命中标准字段 `aliases` 中的任一别名。
- 字段候选：未命中标准字段库的列，保留原字段名、数据类型、注释和可空信息。
- 非标准字段：未命中标准字段库的列，同时给出推荐字段名；第一版推荐值使用原字段名，后续可接字段推荐服务。
