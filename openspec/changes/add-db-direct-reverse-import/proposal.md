## 背景

P4-11 需要把现有“粘贴 SQL DDL 反向导入预览”升级为“数据库直连反向导入”。当前用户只能先从数据库导出建表 SQL，再粘贴到 DataSpec；这不适合真实已有库的批量梳理。

## 变更

- 新增数据库直连反向导入 API，支持 PostgreSQL/MySQL 连接测试、schema/table 读取和 metadata 预览。
- 复用现有反向导入差异模型，生成解析表、字段候选、缺注释项、非标准字段差异和导入统计。
- 新增确认导入 API，将用户确认的字段候选写入当前项目字段库，并跳过已存在字段。
- 前端反向导入页新增“数据库直连”模式，提供连接表单、连接测试、表选择、预览和确认导入流程。

## 非目标

- 不保存数据库密码。
- 不做定时同步。
- 不自动修改源数据库。
- 不做审批流或复杂权限模型。
- 第一版仅支持手动确认导入到当前项目字段库。
