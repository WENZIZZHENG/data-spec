## 背景

P2-5 需要让个人/小团队能用 Excel 批量维护字段标准和代码集。当前系统只有 JSON 字段导入导出，无法覆盖别名、分类、代码集关联，也没有导入前预览和错误报告。

## 变更

- 增加标准字段与代码集的 `.xlsx` 模板下载、项目数据导出、导入预览和确认导入接口。
- Excel 第一版包含 `fields`、`enum_dicts`、`enum_values` 三张 Sheet。
- 导入预览按项目内字段名、代码集编码和枚举值判断新增/更新，并报告缺必填项、重复行、未知数据域或未知代码集等错误。
- 导入确认采用 upsert：先导入/更新代码集，再导入/更新枚举值，最后导入/更新字段和代码集关联。
- 导入导出页面提供模板下载、项目 Excel 导出、上传预览、确认导入和错误展示。

## 非目标

- 不做复杂冲突合并、审批流或多人协作锁。
- 不导入数据域，字段的 `domainCode` 只允许关联现有数据域。
- 不支持 `.xls`，第一版只支持 `.xlsx`。
